# E-Commerce Sales Analysis

## Project Overview

This project analyzes e-commerce sales data using Microsoft Excel to identify sales trends, customer patterns, and business performance.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel Formulas
* Data Cleaning
* Data Visualization

## Key Analysis

* Total Orders
* Total Customers
* Total Sales
* Average Order Value
* Monthly Sales Trends
* Sales by Category
* Orders by City
* Top Products/Categories

## Dashboard

An interactive Excel dashboard was created to present important business KPIs and sales insights in an easy-to-understand format.

## Skills Demonstrated

* Data Cleaning
* Data Analysis
* Pivot Tables
* Data Visualization
* Dashboard Creation
* Business Insights
